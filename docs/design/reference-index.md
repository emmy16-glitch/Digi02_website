## 12. Reference usage rule

When implementing from a reference:

1. Identify the component/layout principle being borrowed.
2. Recreate it using Digi02 content and approved tokens.
3. Use production-quality Digi02 imagery or purpose-built SVG/HTML.
4. Verify that no original reference branding/artwork remains.
5. Confirm the result still matches `DIGI02-DESIGN-SYSTEM.md` and `DIGI02-PAGE-BLUEPRINT.md`.

The goal is not `Watermelon UI recolored gold`.

The goal is a consistent Digi02 system informed by the best composition ideas from the reference set.
