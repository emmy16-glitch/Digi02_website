# Digi02 Page Blueprint

**Status: LOCKED / APPROVED BASELINE**

This document defines the approved section order and design intent for each Digi02 page. Section IDs are stable implementation references. Do not materially change section order, purpose or visual role without first updating this document through change control.

---

# 1. Home

The homepage is the master expression of the Digi02 design system.

## H01 — Cinematic Hero

Purpose: communicate Digi02's operational technology position immediately.

Content:

- headline: `Technology built for real operations.`
- concise supporting copy;
- primary CTA: `Explore our work`;
- secondary CTA: `See our solutions`;
- origin proof line: `Built in Kaduna. Engineered for impact.`

Visual direction:

- clear, high-detail Digi02 operations-room / national operations environment;
- Nigeria/Kaduna context, live infrastructure, mapping and operational data may appear;
- one coherent cinematic environment, not a stack of unrelated floating HUD cards;
- no blurry screenshots or stretched dashboard imagery.

## H02 — Proof Strip

Immediately below hero.

Metrics:

- `100+` Projects delivered
- `50+` Clients across sectors
- `10+` States impacted
- `ISO 27001` Security & quality

Treatment: black background, gold line icons, warm-white numbers, minimal dividers.

## H03 — Solutions + Featured Case Study

Warm-white editorial section.

Left side:

- eyebrow: `Our Solutions`
- heading: `Purpose-built technology. Measurable impact.`
- three clean information cards with no large image inside:
  - SkyGrid
  - DigiVolt
  - Enterprise Systems

Each card: gold circular icon, title, one concise sentence, `Learn more →`.

Right side:

- large dark featured case-study card;
- project: `Thermal Plant Inspection Automation`;
- clear visual occupying roughly 45–50% of card;
- copy area contains a real `Operational workflow`, not decorative empty space:
  1. Plan the mission
  2. Capture field data
  3. Review operations
- `View case study →`.

## H04 — What Digi02 Does

Warm-white section using four matching cards:

- We Build
- We Automate
- We Electrify
- We Secure

Every card uses the same gold-outline circular icon treatment, short copy and tertiary arrow action.

## H05 — Editorial Philosophy Break

Dark, minimal section with generous breathing room.

Eyebrow: `Our Approach`

Statement:

`Technology should fit the operation — not force the operation to fit the technology.`

No cards, no dashboard screenshot, no decorative clutter.

## H06 — Selected Work

Three major project cards with consistent visual quality and media ratios:

- Thermal Plant Inspection Automation
- Sterling Payment Gateway
- Kaduna State e-Management System

Each card:

- clear purpose-built visual;
- category;
- title;
- concise explanation;
- `View case study →`.

Do not mix a blurry screenshot, stock photo and raw dashboard export in one row.

## H07 — Built in Kaduna

Dark proof section.

Content:

- restrained Africa outline / regional motif;
- heading: `Built in Kaduna. Building for Africa.`
- short positioning copy;
- compact proof metrics, visually secondary to H02.

## H08 — Final CTA

Dark CTA using restrained black/charcoal/gold wave or data-flow motif.

Copy:

- `Have a project in mind?`
- short supporting line;
- `Discuss your project →`.

## H09 — Global Footer

Use the shared footer specification.

# 2. Solutions

The Solutions page is a catalogue of operational systems, not a dashboard gallery.

## S01 — Hero

Headline: `Technology solutions for real operations.`

Left: headline, concise copy, two value points.

Right: one coherent systems / national operations visual with a restrained trust block. Do not overload with floating widgets.

## S02 — Category Navigation

Approved filters:

- All Solutions
- Autonomous Systems
- Enterprise
- Finance & Payments
- Automation
- Digital Platforms

Desktop: horizontal. Mobile: horizontally scrollable. Selected filter: gold pill.

## S03 — Flagship SkyGrid

Full-width featured product.

Content:

- SkyGrid title;
- autonomous UAV positioning;
- 2–3 compact capabilities;
- `Learn more →`;
- dedicated high-quality UAV / inspection / field-operations visual.

Never use a low-resolution cropped dashboard as the flagship image.

## S04 — Product Grid

Two-column desktop grid:

- DigiVolt
- Enterprise Systems
- Payment Systems
- E-Management

Each gets a distinct visual concept:

- DigiVolt: energy, vehicle, charging/infrastructure;
- Enterprise: workflows, business operations, reporting;
- Payment: POS, transaction, settlement/payment operations;
- E-Management: institutional workflows, approvals, service delivery.

No image recycling between products.

## S05 — Built for Real Operations

Reusable four-principle strip:

- Secure by design
- Built to scale
- Designed around people
- Supported locally

## S06 — Custom Software Feature Split

Large horizontal split layout.

Left:

- Custom Software
- `Software built around the operation — not the other way round.`
- Discovery
- Modern engineering
- Support & evolution

Right:

- crisp layered Digi02 product/interface panels or purposeful illustration;
- no generic unrelated dashboard.

## S07 — Solutions FAQ

Use the reusable numbered accordion.

Questions:

1. Can Digi02 integrate with existing systems?
2. Are solutions customizable?
3. Do you support multi-site deployments?
4. How does Digi02 approach security?
5. What support is available after launch?

## S08 — CTA

`Not sure which solution fits?`

Gold primary CTA.

# 10. Implementation rule

When implementing any page:

1. Identify the relevant section IDs in this file.
2. Match the approved content hierarchy and visual purpose.
3. Use shared components from the design system where possible.
4. Follow `DIGI02-ASSET-RULES.md` for all imagery.
5. Follow `DIGI02-RESPONSIVE-RULES.md` before writing breakpoint fixes.
6. Complete `DIGI02-QA-CHECKLIST.md` before merge.

If a proposed implementation materially differs from this blueprint, update and approve the blueprint first.
