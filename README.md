# Digi02 website

React, TypeScript, and Vite foundation for the Digi02 corporate website.

## Local development

```sh
npm install
npm run dev
```

Open `http://localhost:5173/foundation` to review the internal design-foundation preview.

## Validation

```sh
npm run typecheck
npm run lint
npm run build
```

Phase 0 contains only the project foundation, global design tokens, baseline styles, and internal preview. No public website pages have been built.
